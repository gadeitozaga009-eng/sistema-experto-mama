# Sistema Experto de Oncología Mamaria

Versión profesional para Streamlit.

## Archivos
- `app.py`
- `requirements.txt`
- `.streamlit/config.toml`

## Ejecución local
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Despliegue
Sube los tres elementos al repositorio de GitHub. Es importante incluir la carpeta `.streamlit` con `config.toml`.
